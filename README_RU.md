# Ассеты GOAT.exe

На следующем этапе сюда можно положить PNG с прозрачным фоном:
- goat_idle.png — обычная поза
- goat_happy.png — событие `!pet`
- goat_eating.png — событие `!feed`
- goat_chaos.png — событие `!chaos`
- goat_duel.png — событие `!duel`
- food.png — корм
- fx_spark.png — искры
- fx_glitch.png — глитч

Рекомендуемый размер 512×512 или 1024×1024 px, с альфа-каналом.
